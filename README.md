## 🚀 Projetos em Destaque

### 🌤️ Weather DataViewer Dashboard

Dashboard completo para monitoramento de dados meteorológicos em tempo real com:

- **FastAPI** backend com endpoints RESTful
- **PostgreSQL/TimescaleDB** para armazenamento de séries temporais
- **Docker** containerização com Docker Compose
- **Highcharts** para visualizações interativas
- Simulação automática de 8 sensores meteorológicos
